================================================================================
Google Antigravity (AGY) - Windows Troubleshooting & Unblocking Guide
================================================================================

If you see this error when double-clicking agy.cmd or agy-admin.cmd:

  "Windows no puede acceder al dispositivo, la ruta de acceso o el archivo
   especificados. Puede que no tengas los permisos apropiados para acceder
   al elemento."

Or if Windows says "Acceso denegado":

This is caused by standard Windows 11 security mechanisms:
1. Windows Mark of the Web (Zone.Identifier): When zip files are downloaded
   from the internet, Windows marks extracted scripts as untrusted on USB drives.
2. Removable Storage Execution Restrictions: Windows 11 prevents running
   executables directly off USB flash drives.

--------------------------------------------------------------------------------
SOLUTION 1: RUN THE ONE-CLICK UNBLOCK TOOL (Recommended)
--------------------------------------------------------------------------------
1. In the Windows folder, double-click:
   Unblock.cmd
2. Wait 2 seconds for it to finish.
3. You can now launch agy.cmd or agy-admin.cmd normally without any blocks.

--------------------------------------------------------------------------------
SOLUTION 2: RUN AS ADMINISTRATOR ONCE
--------------------------------------------------------------------------------
1. Right-click agy-admin.cmd.
2. Click "Run as administrator" (Ejecutar como administrador).
3. Click "Yes" on the Windows prompt.
4. The launcher will automatically unblock the USB files in the background.

--------------------------------------------------------------------------------
SOLUTION 3: UNBLOCK VIA FILE PROPERTIES
--------------------------------------------------------------------------------
1. Right-click agy.cmd and click Properties (Propiedades).
2. At the bottom of the General tab, look for "Security" (Seguridad).
3. Check the box that says "Unblock" (Desbloquear).
4. Click Apply and OK.
5. Repeat for agy-admin.cmd if necessary.

--------------------------------------------------------------------------------
HOW AGY RUNS SECURELY FROM USB
--------------------------------------------------------------------------------
To bypass Windows 11's block on running programs directly from USB flash drives:
- AGY-Portable automatically loads the core CLI engine into a temporary sandbox
  folder on the PC while showing a loading progress indicator.
- 100% of your login credentials, OAuth tokens, and conversation history remain
  strictly on your USB drive (data\home\.gemini).
- When you exit, the temporary sandbox on the PC is immediately purged, leaving
  zero footprint on the host computer.
